# Yann Seven OS

Sistema operacional leve inspirado no Windows 7 e personalizado para Yann Emanoel Mendes, otimizado para rodar em hardware modesto e caber em pendrives de 4GB via OTG.

## Recursos Incluídos:
- **Identidade:** Yann Seven OS
- **Word e Excel:** Atalhos dedicados para documentos e planilhas.
- **Guardião de Cache:** Sistema inteligente que compacta caches acima de 195GB e limpa dados inativos a cada hora.
- **Gerenciador de Memória:** ZRAM, EarlyOOM e painel interativo.
- **Jogos e Apps:** Roblox Studio, Unity Hub, Super Mario 64 (RetroArch), Oxid, Google Chrome, YouTube e Play Store (Waydroid).
